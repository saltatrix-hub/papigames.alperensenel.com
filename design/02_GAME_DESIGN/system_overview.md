# SYSTEM OVERVIEW

## Core Loops
1. Quest -> Combat -> Loot -> Upgrade -> New zone
2. Dungeon -> Set pieces -> Enhancement -> Raid readiness
3. Gathering -> Crafting -> Market -> Gold sink -> Economy loop
4. Daily/Weekly -> Reputation -> Cosmetics/utility -> Seasonal loop
